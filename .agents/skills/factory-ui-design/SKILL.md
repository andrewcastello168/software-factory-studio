# Studio UI design

1. Read the assigned phase in [Roadmap](../../../docs/ROADMAP.md) and the applicable sections of [UI design system](../../../docs/UI_DESIGN_SYSTEM.md).
2. Identify the active scope and the commands that already work. Use semantic tokens and compact desktop controls. Keep project, directory, branch and status understandable when a project is active.
3. Implement shortcut, menu, and toolbar actions through shared command state. Handle focus, keyboard access and real loading, empty, error and recovery states as applicable.
4. Exercise the normal path with pointer and keyboard in both themes. Verify accessible names, focus restoration, layout sizes and zoom relevant to the phase.
5. Record renderer results and any missing native evidence in [Progress](../../../docs/PROGRESS.md).
