# Studio stack adapters

1. Read the [Stack plugin SDK](../../../docs/STACK_PLUGIN_SDK.md) and the current gates in [Roadmap](../../../docs/ROADMAP.md).
2. Add exact stack and architecture IDs, declare supported combinations, and keep templates and executable registration in the reviewed build. Verify existing output bytes before changing a shared template.
3. Keep workspace authority in main. Use the shared schema, planner finalization, ownership, approval and recovery. Keep generated runtimes and document instructions specific to the selected stack.
4. Run generated projects in disposable directories and PostgreSQL schemas. Verify exact dependency manifests, cross-stack rejection, production execution, and both target platforms. Record the evidence in [Progress](../../../docs/PROGRESS.md).
